# 发现

## 研究问题

单场 events 与 360 是否能在明确的数据边界下可靠关联并用于后续空间测量？

## 数据范围

- 赛事和赛季：La Liga 2020/2021。
- 比赛或样本：Barcelona 1–3 Real Madrid，match ID `3773585`。
- 上游 commit：`b0bc9f22dd77c206ddedc1d742893b3bbe64baec`。
- 排除项：压力分类、build-up episode、战术结果和样本外验证。

## 结果

### event–360 关联完整

- 证据层级：数据事实。
- 样本：全场 4,213 条 events 和 3,858 个 360 frames。
- 算法：按 `event.id == frame.event_uuid` 关联；每个集合内分别检查空 ID 和重复 ID。
- 结果：3,858 个 frame 全部匹配唯一 event；空 ID、重复 ID 和无法匹配 frame 均为
  0。355 条 event 没有 360，event 层面的 frame 覆盖率为 91.6%。
- 足球读法：后续可以为 3,858 个有冻结画面的事件构造空间特征，但不能假定每条
  event 都能观察周边球员。
- 不能据此确认：未被 360 覆盖的事件是否与已覆盖事件具有相同分布。
- 增强可信度的检查：在未来 10 场探索集逐场报告覆盖率，而不是只报告合并均值。

### 坐标字段结构可靠，但 freeze-frame 线外球员不是错误

- 证据层级：数据事实与指标结果。
- 样本：4,186 个 event 起点、2,226 个事件终点、65,283 个 freeze-frame 球员位置
  和 22,457 个 visible-area 顶点。
- 算法：检查坐标至少有两个有限数值，并以包含边界的 `0–120 x 0–80` 作为球场线
  内范围。
- 结果：event 起点、事件终点和 visible-area 顶点均无畸形或线外值；freeze-frame
  坐标无畸形值，但有 377 个（0.58%）位于球场线外。
- 足球读法：360 可以记录边线外的球员位置，验证器应保留并报告，而不是裁剪或删除。
- 不能据此确认：线外位置的具体比赛情境或位置估计误差，需要逐场事件或视频核查。
- 增强可信度的检查：按事件类型抽查线外坐标，并在多场样本比较其比例和范围。

### freeze-frame 容器和可见区域通过关键断言

- 证据层级：数据事实。
- 样本：3,858 个 360 frames。
- 算法：检查 freeze-frame 是否为非空列表、球员标记是否为布尔值、每帧 actor 数量
  以及 visible-area 是否存在并由有效点对构成。
- 结果：空或畸形 frame、畸形球员标记、缺失或畸形 visible area、多 actor frame 和
  actor 不可见 frame 均为 0。
- 足球读法：本场的 frame 容器可以进入后续可见压力测量，但 visible area 仍只表示
  供应商在事件瞬间覆盖的画面。
- 不能据此确认：画面外没有对手或传球路线，也不能恢复连续跑动和压迫触发过程。
- 增强可信度的检查：未来对门将事件单独计算 360 覆盖和画面范围，而不沿用全事件
  覆盖率代表目标样本。

### 两队两半场都使用统一向右进攻坐标

- 证据层级：指标结果。
- 样本：全场 26 次射门，按球队与 period 分为 Barcelona `5 + 5`、Real Madrid
  `6 + 10`。
- 算法：按球队和 period 汇总射门起点 x，并绘制在同一 StatsBomb 球场坐标上。
- 结果：四组射门全部发生在 `x >= 60`；中位起点 x 依次为 97.5、108.8、108.75、
  106.55。第二半场没有因真实换边而改变数据中的进攻方向。
- 足球读法：后续比较向前移动时不应按半场再次翻转坐标。
- 不能据此确认：射门位置集中在右侧球门的战术原因或射门质量。
- 增强可信度的检查：迁移到另一场比赛，并结合 Pass/Carry 的前进方向做第二种
  sanity check。

## 敏感性与反证

- 替代定义：若把球场范围改为不含边界，会把合法边线/球门线坐标误报为异常。
- 反例：freeze-frame 线外坐标推翻了“所有空间坐标都必须在线内”的初始假定。
- 稳定性检查：本课只检查单场；多场迁移属于后续课程。

## 限制

- 事件数据的可见范围：360 是事件瞬间的部分画面，不是连续 tracking。
- 样本与语境：单场质量检查不能证明赛季范围的覆盖稳定性。
- 测量：visible area 外的球员不能被解释为不存在。

## 结论

本场 events 与 360 能以唯一 UUID 完整关联，关键容器和 event 坐标检查通过，可以
生成 3,858 行可复用基础场景表。这个结论只表示“数据已准备好进入测量”，不表示
压力、出球选择或 build-up 结果已经被定义，更不支持任何战术因果结论。
