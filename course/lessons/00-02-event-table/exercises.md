# 练习

## 解释

不阅读实现代码，解释：

- 为什么传球距离图使用成功 Regular Play Pass，而热图使用全部 Pass 起点？
- 为什么 KDE 的两队颜色不能直接比较绝对次数，而共享尺度 hexbin 可以？
- 为什么 Messi 的两张图不能称为连续移动热区？
- 在四类证据层级中，哪项结论最可靠，哪项最不确定？

## 迁移

换一场同时具有 events 与 lineups 的比赛重复分析。运行前预测：

- 哪队的成功 Regular Play 传球均值更长；
- 哪队更早达到第 5 次射门；
- 第一次换人前哪队的 network 样本更多。

保留同一分箱、共同换人窗口和共享视觉尺度，确保差异来自样本而不是绘图口径。

## 质疑定义

- 把距离样本改为全部 Pass，比较均值和右尾怎样变化，并解释 restart 的影响。
- 将 network 的边阈值从 3 改为 5，区分“图上不显示”与“传球没有发生”。
- 改变 KDE 带宽或 `levels`，指出哪些视觉变化来自参数而不是足球行为。
- 在累计射门旁增加累计 xG，比较数量领先与机会质量领先是否同时发生。
